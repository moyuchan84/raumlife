# Raumlife 빌더 (3D 복셀 건축)

```bash
npm run build:builder   # builder/dist/main.js 생성
# 그다음 builder/index.html 을 브라우저로 열기 (또는 정적 서버)
```

- 🛠️ 건축 모드: 날아다니며 블록·가구 설치, 땅 올리기/내리기/평탄화, 수영장 생성, 64칸 높이(16층)
- 가구 30종+: 소파(베이지·회색·검정·하양·부드러운·푹신한·가죽·1인), TV(작은·중간·큰·초대형), 침대(작은·푹신한·퀸·킹·안마·2층), 식탁·책상·옷장·욕조 등. 2~3칸짜리 큰 가구 지원
- 부드러운 그림자·모서리 음영(AO)·둥근 가구로 블록 느낌 줄임
- 낮·밤: 시간 슬라이더(☀️낮·🌙밤 버튼, ▶ 시간 흐름, T 키 +3시간), 일출·일몰 하늘, 별, 스탠드 조명·TV 불빛이 밤에 방을 비춤
- 🏠 생활 모드: 걷기·점프·계단 오르기·사다리·수영, `E`로 소파/침대에 앉기, TV·조명 켜고 끄기
- 지형 프리셋(평지/언덕/호수/섬/설산) + 시드, 로컬 저장/불러오기
